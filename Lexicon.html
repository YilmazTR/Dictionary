Your words. Your files.

A working browser preview, and a Python desktop app you can take with you.

This page stores your dictionary in this browser. Export a JSON backup to keep it safe. The downloadable Python app reads and writes your own dictionary file directly; it works on Windows and macOS without third-party packages.

01 / Get the app

Download all three files into one folder. Install Python 3.10 or newer, then run python lexicon.py (or python3 lexicon.py on macOS). The setup dialog asks you to create a blank JSON dictionary or open an existing one.

02 / Make connections

Direct: a straightforward meaning, such as “look at = bakmak.” Aligned: link individual source words to target words with the positioning control. Expression: preserve the whole idiom, such as “take someone for granted = birisini çantada keklik görmek.”

Direct translation is the default. Word counts need not match: the app stores the text as written. Choose aligned mode when word positioning is useful, not when the translation is idiomatic.

03 / Remember for longer

New entries are due immediately. An SM-2-inspired scheduler uses your recall rating to adjust intervals and ease. Successful reviews progress from 1 day to 6 days, then to increasingly longer intervals. “Again” resets the successful-review streak and brings the item back in 10 minutes.

Spaced repetition and active recall are research-supported principles, not a guarantee of retention. Review reminders appear while the app is open; there are no background notifications.

04 / Keep a backup

Export this browser dictionary, then open it in the Python app. Both use the same JSON format, including creation times, word alignment, review history, and scheduling data.
